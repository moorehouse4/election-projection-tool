# Security Policy

## Reporting a Vulnerability

If you find a security issue with this project, please do not open a public GitHub issue.

Instead, contact the project maintainer privately.

## Scope

This project is a public election projection tool. Users can upload election result files and paste public results links to generate projections.

The tool does not intentionally collect, store, or publish uploaded files.

## Data Handling

Uploaded files are processed temporarily during the user’s session. Users should not upload sensitive personal information, private electoral roll data, passwords, API keys, or confidential campaign material.

## Disclaimer

This tool provides unofficial projections only. It is not authorised by, affiliated with, or endorsed by the VEC, AEC, or any electoral commission.
